Modul Lengkap Konfigurasi MikroTik RouterOS

Modul komprehensif ini menggabungkan seluruh tahapan konfigurasi RouterOS secara runtut dari awal hingga akhir, meliputi Konfigurasi Dasar MikroTik, Konfigurasi Internet WAN (ether3) & Routing Default, Konfigurasi IP LAN (ether4), DHCP Server & Hotspot, hingga Firewall Filter Rules, Pemblokiran File & Pemblokiran Web.

A. Landasan Teori

1. Konfigurasi Dasar MikroTik RouterOS & WinBox

MikroTik RouterOS adalah sistem operasi berbasis Linux yang dirancang khusus untuk menjadikan komputer atau perangkat keras RouterBOARD berfungsi sebagai router jaringan yang andal. Manajemen router umumnya dilakukan menggunakan WinBox, aplikasi GUI yang memungkinkan konfigurasi visual via MAC/IP Address. Pengaturan dasar mencakup penentuan Identity Router agar mudah diidentifikasi, pengubahan Password Account untuk keamanan dasar, konfigurasi DNS Server (termasuk Allow Remote Requests sebagai DNS Forwarder/Cache LAN), dan sinkronisasi waktu otomatis melalui NTP Client (SNTP).

2. Konfigurasi Internet WAN (ether3), Routing Default & NAT

Penghubungan router ke jaringan internet pada interface WAN (ether3) memanfaatkan DHCP Client untuk mendapatkan IP address, subnet mask, default gateway, dan DNS server secara otomatis dari ISP. Rute default (0.0.0.0/0) secara dinamis mengarahkan lalu lintas tak dikenal ke gateway ISP. Selain itu, aturan NAT (Network Address Translation) Masquerade diaktifkan untuk menerjemahkan alamat IP privat lokal menjadi IP publik saat berkomunikasi ke internet.

3. Konfigurasi IP LAN, IP Pool, DHCP Server & Hotspot Gateway

Pengalamatan jaringan lokal (ether4) dikelola dengan menentukan IP Address static gateway, lalu mengatur IP Pool sebagai rentang alokasi IP yang akan didistribusikan oleh DHCP Server kepada klien secara otomatis. Untuk otentikasi berbasis captive portal, Hotspot Gateway diaktifkan. Melalui User Profiles, administrator dapat membatasi hak akses serta kecepatan bandwidth unggah/unduh (Rate Limit rx/tx) untuk grup pengguna tertentu (misalnya Guru dan Siswa).

4. Firewall Filter Rules, Pemblokiran File & Web

Firewall Filter memeriksa setiap paket data berdasarkan titik pemeriksaannya:

  • Chain Input: Menangani paket data yang ditujukan langsung ke router (contoh: ping ICMP dari klien ke IP Gateway router).
  • Chain Forward: Menangani paket data yang melintasi router dari satu segmen/klien menuju segmen/klien lain atau ke internet.

Untuk keamanan dan manajemen lalu lintas, dilakukan pemblokiran paket ICMP (Ping), pemblokiran unduhan file (.mp3), serta pemblokiran situs web (contoh: tkjapps.smksabdev.my.id) menggunakan kombinasi metode TLS Host, Layer7 Protocol (Regexp), Firewall Content, dan Web Proxy Access.

B. Langkah Kerja Konfigurasi Runtut (1–11)

PETUNJUK UMUM:
  • Persiapan: Hubungkan kabel UTP dari Port Ethernet PC ke port ether2 pada RouterBOARD. Buka WinBox, pilih MAC Address router di tab Neighbors, lalu klik Connect.
  • Ketentuan Variable IP: Ganti variabel xx pada seluruh IP Address dengan Nomor Absen Siswa. (Contoh: Absen 05 → 172.32.5.1/24).
Langkah 1: Mengganti Identity Router
  1. Buka menu System → Identity.
  2. Pada kolom Name, ketik identitas baru: Router-NamaSiswa (Contoh: Router-Budi).
  3. Klik tombol Apply, lalu OK.
  4. Amati perubahan nama router pada bagian title bar aplikasi WinBox.
Langkah 2: Mengubah Password Router
  1. Buka menu System → Password.
  2. Biarkan kolom Old Password kosong (jika default).
  3. Isi kolom New Password dan Confirm Password dengan password baru.
  4. Klik tombol Change.
Langkah 3: Konfigurasi DNS Server
  1. Buka menu IP → DNS.
  2. Pada kolom Servers, klik panah bawah, tambahkan DNS Static: 103.172.172.4.
  3. Centang opsi Allow Remote Requests.
  4. Klik tombol Apply, lalu OK.
Langkah 4: Konfigurasi NTP Client (Sinkronisasi Waktu)
  1. Buka menu System → NTP Client (atau SNTP Client).
  2. Berikan centang pada opsi Enabled.
  3. Isi kolom Server DNS Names: time.windows.com.
  4. Klik tombol Apply, lalu OK.
  5. Pastikan status berubah menjadi synchronized dan waktu router terupdate secara otomatis.
Langkah 5A: Konfigurasi DHCP Client pada ether3 (Koneksi Internet)
  1. Buka menu IP → DHCP Client → Klik tombol +.
  2. Pada jendela yang muncul, isi konfigurasi berikut:
    • Interface: Pilih ether3 (interface yang terhubung ke modem/ISP).
    • Use Peer DNS: ✓ Centang (agar DNS dari ISP otomatis digunakan).
    • Add Default Route: ✓ Centang (agar gateway default otomatis ditambahkan ke routing).
  3. Klik OK untuk menyimpan konfigurasi.
  4. Tunggu beberapa saat hingga status berubah menjadi bound (berhasil mendapatkan IP dari ISP).
✓ INDIKASI BERHASIL: Pada daftar DHCP Client, akan muncul IP Address, Gateway, dan DNS Server yang diberikan oleh ISP secara otomatis.
Langkah 5B: Verifikasi Default Route
  1. Buka menu IP → Routes untuk memverifikasi rute default.
  2. Pastikan terdapat entri otomatis dengan Dst. Address: 0.0.0.0/0 dan Gateway yang terisi IP Gateway dari ISP via ether3.
  3. Perhatikan flag di sebelah kiri entri tersebut bertuliskan DA atau DAS (Dynamic Active Static / Dynamic Active), menandakan rute aktif secara dinamis.
Langkah 5C: Konfigurasi NAT Masquerade
  1. Buka menu IP → Firewall → NAT → Klik tombol +.
  2. Pada tab General, isi:
    • Chain: srcnat
    • Out. Interface: ether3 (interface WAN yang terhubung ke internet)
  3. Pada tab Action, isi:
    • Action: masquerade
  4. Klik OK untuk menyimpan aturan NAT.
✓ SELESAI: Router sekarang telah terhubung ke internet secara dinamis melalui DHCP Client pada ether3 dan siap meneruskan koneksi internet ke jaringan lokal.
Langkah 6: Konfigurasi IP LAN (ether4) & DHCP Server
  1. IP Address LAN: Buka IP → Addresses → Klik +. Isi Address: 172.32.xx.1/24 | Interface: ether4 → OK.
  2. IP Pool: Buka IP → Pool → Klik +. Isi Name: dhcp-pool-lan | Addresses: 172.32.xx.21-172.32.xx.70 → OK.
  3. DHCP Setup: Buka IP → DHCP Server → Klik DHCP Setup.
    • Select Interface: ether4 → DHCP Address Space: 172.32.xx.0/24 → Gateway: 172.32.xx.1.
    • Addresses to Give Out: 172.32.xx.21-172.32.xx.70 → DNS: 172.32.xx.1 → Klik Next hingga selesai.
Langkah 7: Konfigurasi Hotspot & User Profiles
  1. Hotspot Setup: Buka IP → Hotspot → Servers → Klik Hotspot Setup.
    • Interface: ether4 | Local Address: 172.32.xx.1/24 | Pool: dhcp-pool-lan.
    • Certificate: none | SMTP: 0.0.0.0 | DNS Server: 172.32.xx.1 | DNS Name: wifi-namasiswa.com → Next.
  2. User Profiles: Buka tab User Profiles → Klik +:
    • Guru: Name: profile-guru | Rate Limit (rx/tx): 10M/10M → OK.
    • Siswa: Name: profile-siswa | Rate Limit (rx/tx): 5M/5M → OK.
  3. Users Hotspot: Buka tab Users → Klik +:
    • Akun Guru: Name: guru | Pass: guru | Profile: profile-guru → OK.
    • Akun Siswa: Name: siswa | Pass: siswa | Profile: profile-siswa → OK.
Langkah 8: Firewall - Blokir Ping DHCP Pool ke Router
  1. Buka menu IP → Firewall → Filter Rules → Klik tombol +.
  2. Tab General:
    • Chain: input
    • Src. Address: 172.32.xx.21-172.32.xx.70
    • Protocol: icmp
  3. Tab Action:
    • Action: drop
  4. Klik Apply, lalu OK.
Langkah 9: Firewall - Blokir Ping IP Pool 21-30 ke IP 61-70
  1. Buka menu IP → Firewall → Filter Rules → Klik tombol +.
  2. Tab General:
    • Chain: forward
    • Src. Address: 172.32.xx.21-172.32.xx.30
    • Dst. Address: 172.32.xx.61-172.32.xx.70
    • Protocol: icmp
  3. Tab Action:
    • Action: drop
  4. Klik Apply, lalu OK.
Langkah 10: Pemblokiran File .mp3 (Metode Utama & Alternatif)
  1. Metode 1 (Layer7 Protocol - Utama):
    • Buka IP → Firewall → Layer7 Protocols → Klik tombol +. Name: block-mp3 | Regexp: ^.*\.mp3.*$ → Klik OK.
    • Buka tab Filter Rules → Klik +.
    • Tab General: Chain: forward | Src. Address: 172.32.xx.0/24 | Protocol: tcp
    • Tab Advanced: Layer7 Protocol: block-mp3
    • Tab Action: Action: drop → Klik Apply, lalu OK.
  2. Metode 2 (Firewall Content - Alternatif):
    • Buka IP → Firewall → Filter Rules → Klik tombol +.
    • Tab General: Chain: forward | Protocol: tcp | Dst. Port: 80 | Src. Address: 172.32.xx.0/24
    • Tab Advanced: Content: .mp3
    • Tab Action: Action: drop → Klik Apply, lalu OK.
  3. Metode 3 (Web Proxy Access - Alternatif):
    • Aktifkan Web Proxy: Buka IP → Web Proxy. Centang Enabled | Port: 8080 | Centang Anonymous → Klik Apply.
    • Aturan Blokir: Pada jendela Web Proxy, klik Access → Klik +. Path: *.mp3 | Action: deny → Klik OK.
    • Redirect HTTP ke Proxy (NAT): Buka IP → Firewall → NAT → Klik +. Chain: dstnat | Protocol: tcp | Dst. Port: 80 | In. Interface: ether4 | Action: redirect | To Ports: 8080 → Klik OK.
Langkah 11: Pemblokiran Situs Web (Contoh: tkjapps.smksabdev.my.id)
  1. Metode 1: Menggunakan TLS Host (Sangat Ringan & Efektif HTTPS/HTTP)
    • Buka menu IP → Firewall → Filter Rules → Klik tombol +.
    • Tab General: Chain: forward | Protocol: tcp | Dst. Port: 443,80
    • Tab Advanced: TLS Host: *tkjapps.smksabdev.my.id*
    • Tab Action: Action: drop → Klik Apply, lalu OK.
  2. Metode 2: Menggunakan Layer7 Protocol (Regexp Target Domain)
    • Buka IP → Firewall → Layer7 Protocols → Klik tombol +. Name: block-web-tkjapps | Regexp: ^.*(tkjapps\.smksabdev\.my\.id).*$ → Klik OK.
    • Buka tab Filter Rules → Klik tombol +.
    • Tab General: Chain: forward | Src. Address: 172.32.xx.0/24 | Protocol: tcp
    • Tab Advanced: Layer7 Protocol: block-web-tkjapps
    • Tab Action: Action: drop → Klik Apply, lalu OK.
  3. Metode 3: Menggunakan Web Proxy Access (Untuk Protokol HTTP)
    • Pastikan Web Proxy sudah aktif (seperti pada Langkah 10 Metode 3).
    • Buka IP → Web Proxy → Access → Klik tombol +.
    • Dst. Host: *tkjapps.smksabdev.my.id*
    • Action: deny → Klik Apply, lalu OK.
