Modul 02

Konfigurasi Internet (ether3) & Routing Default

Modul ini membahas langkah-langkah penghubungan router ke internet melalui interface ether3 menggunakan DHCP Client, penentuan jalur Default Gateway secara otomatis, serta aktivasi aturan NAT Masquerade.

A. Landasan Teori

1. DHCP Client pada Interface WAN (ether3)

DHCP Client berfungsi meminta konfigurasi IP address, subnet mask, default gateway, dan DNS server secara otomatis dari ISP (Internet Service Provider). Metode ini lebih praktis karena tidak memerlukan konfigurasi manual IP statis.

2. Default Gateway (0.0.0.0/0)

Default route dengan alamat tujuan 0.0.0.0/0 mengarahkan seluruh lalu lintas data yang tujuannya tidak diketahui di tabel routing lokal menuju router milik ISP (Gateway ISP). Pada DHCP Client, gateway ini diperoleh secara otomatis.

3. NAT (Network Address Translation) Masquerade

Aturan NAT dengan aksi Masquerade berfungsi menerjemahkan alamat IP lokal privat menjadi IP publik yang didapat dari DHCP Client pada ether3 ketika data dikirim ke luar jaringan, sehingga jaringan lokal dapat terhubung ke internet.

B. Langkah Kerja Konfigurasi (Dinamis)

METODE DINAMIS: Konfigurasi ini menggunakan DHCP Client sehingga seluruh pengaturan IP, Gateway, dan DNS diperoleh secara otomatis dari ISP. Tidak diperlukan pengaturan IP statis manual.
Langkah 5A: Konfigurasi DHCP Client pada ether3
  1. Buka menu IP → DHCP Client → Klik tombol +.
  2. Pada jendela yang muncul, isi konfigurasi berikut:
    • Interface: Pilih ether3 (interface yang terhubung ke modem/ISP).
    • Use Peer DNS: ✓ Centang (agar DNS dari ISP otomatis digunakan).
    • Add Default Route: ✓ Centang (agar gateway default otomatis ditambahkan ke routing).
  3. Klik OK untuk menyimpan konfigurasi.
  4. Tunggu beberapa saat hingga status berubah menjadi bound (berhasil mendapatkan IP dari ISP).
✓ INDIKASI BERHASIL: Pada daftar DHCP Client, akan muncul IP Address, Gateway, dan DNS Server yang diberikan oleh ISP secara otomatis.
Langkah 5B: Verifikasi Default Route
  1. Buka menu IP → Routes untuk memverifikasi rute default.
  2. Pastikan terdapat entri otomatis dengan Dst. Address: 0.0.0.0/0 dan Gateway yang terisi IP Gateway dari ISP via ether3.
  3. Perhatikan *flag* di sebelah kiri entri tersebut yang bertuliskan DA atau DAS (Dynamic A**ctive **S**tatic / **D**ynamic **A**ctive), yang menandakan bahwa rute default ini ditambahkan secara **otomatis/dinamis** oleh sistem DHCP Client dan sedang aktif.
Langkah 5C: Konfigurasi NAT Masquerade
  1. Buka menu IP → Firewall → NAT → Klik tombol +.
  2. Pada tab General, isi:
    • Chain: srcnat
    • Out. Interface: ether3 (interface WAN yang terhubung ke internet)
  3. Pada tab Action, isi:
    • Action: masquerade
  4. Klik OK untuk menyimpan aturan NAT.
✓ SELESAI: Router sekarang telah terhubung ke internet secara dinamis melalui DHCP Client pada ether3 dan siap meneruskan koneksi internet ke jaringan lokal.
