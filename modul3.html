Modul 03

Konfigurasi IP LAN, DHCP Server & Hotspot

Modul ini membahas alokasi pengalamatan IP Lokal (ether4), pembuatan DHCP Pool, aktivasi DHCP Server, pembuatan Hotspot Captive Portal, serta pembatasan kecepatan (Rate Limit Bandwidth) per grup pengguna.

A. Landasan Teori

1. IP Pool & DHCP Server

DHCP (Dynamic Host Configuration Protocol) Server bertugas mendistribusikan konfigurasi jaringan (IP Address, Netmask, Gateway, dan DNS) secara otomatis kepada perangkat klien LAN. Rentang IP yang dapat dibagikan dikelola di dalam rentang alokasi khusus yang disebut IP Pool.

2. Hotspot Gateway (Captive Portal)

Hotspot MikroTik adalah fitur otentikasi pengguna berbasis jaringan (Portal Web). Sebelum pengguna dapat mengakses jaringan internet, pengguna diwajibkan melakukan login dengan memasukkan nama pengguna (username) dan kata sandi (password) melalui halaman web otentikasi.

3. Hotspot User Profiles & Rate Limit

User Profiles memungkinkan administrator mengelompokkan aturan otentikasi serta membatasi hak akses pengguna. Salah satu fungsi utamanya adalah menentukan Rate Limit (rx/tx), yaitu pembatasan kecepatan unggah (upload) dan unduh (download) bagi grup pengguna tertentu (contoh: Guru dan Siswa).

B. Langkah Kerja Konfigurasi

CATATAN PENTING: Ganti variabel xx pada seluruh IP Address dengan Nomor Absen Siswa. (Contoh: Absen 05 → 172.32.5.1/24).
Langkah 6: Konfigurasi IP LAN (ether4) & DHCP Server
  1. IP Address LAN: Buka IP → Addresses → Klik +. Isi Address: 172.32.xx.1/24 | Interface: ether4 → OK.
  2. IP Pool: Buka IP → Pool → Klik +. Isi Name: dhcp-pool-lan | Addresses: 172.32.xx.21-172.32.xx.70 → OK.
  3. DHCP Setup: Buka IP → DHCP Server → Klik DHCP Setup.
    • Select Interface: ether4 → DHCP Address Space: 172.32.xx.0/24 → Gateway: 172.32.xx.1.
    • Addresses to Give Out: 172.32.xx.21-172.32.xx.70 → DNS: 172.32.xx.1 → Klik Next hingga selesai.
Langkah 7: Konfigurasi Hotspot & User Profiles
  1. Hotspot Setup: Buka IP → Hotspot → Servers → Klik Hotspot Setup.
    • Interface: ether4 | Local Address: 172.32.xx.1/24 | Pool: dhcp-pool-lan.
    • Certificate: none | SMTP: 0.0.0.0 | DNS Server: 172.32.xx.1 | DNS Name: wifi-namasiswa.com → Next.
  2. User Profiles: Buka tab User Profiles → Klik +:
    • Guru: Name: profile-guru | Rate Limit (rx/tx): 10M/10M → OK.
    • Siswa: Name: profile-siswa | Rate Limit (rx/tx): 5M/5M → OK.
  3. Users Hotspot: Buka tab Users → Klik +:
    • Akun Guru: Name: guru | Pass: guru | Profile: profile-guru → OK.
    • Akun Siswa: Name: siswa | Pass: siswa | Profile: profile-siswa → OK.
